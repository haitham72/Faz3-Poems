BUG-CRIT-02 Events Carousel — All 19 Events Show Only 1/3 of Expected Content
Every event (اليوم الوطني, يوم الشهيد, رمضان, الحج, عيد الفطر, and 14 others) violates the "minimum 10 mentions" threshold and displays approximately one-third of expected poems. Root cause is likely a single broken SQL WHERE clause or pagination bug in the events carousel query that applies to all events simultaneously.
⚡ Critical Impact: Time-sensitive content (رمضان, اليوم الوطني) will be visibly incomplete during the most important cultural moments. One SQL fix likely resolves all 19.
BUG-CRIT-03 Singers Pipeline — 45+ Songs Missing Across 22 Artists
محمد عبده (10 missing), نبيل شعيل (numerous confirmed songs not in DB), ميحد حمد (8), راشد الماجد (6), عبدالمجيد عبدالله (4). The pipeline works correctly for 6 singers, confirming the architecture is sound — but data ingestion was never completed for the majority of the roster.
⚡ Critical Impact: The Singers feature (المؤدون) is the app's key multimedia differentiator. Launching with 45+ missing songs creates immediate negative user reviews.
BUG-CRIT-04 Semantic Score Displays Impossible Values (135%, 115%)
The تطابق دلالي (Semantic Match) percentage badges display values above 100%. The cosine similarity score from OpenAI embeddings (range: 0.0–1.0) is being multiplied by 100 without first being clamped. Fix: apply Math.min(score, 1.0) * 100 before rendering.
⚡ Critical Impact: Destroys user trust immediately. A user seeing "135% match" perceives the app as broken or untrustworthy before reading a single poem.
BUG-HIGH-01 Search Shows Expanded Query Instead of User's Original Query
When a user types "الشوق", the search result header displays the N8N-expanded context_query (e.g. "قصائد عن الشوق والحنين والفراق") instead of the original "الشوق". The original query string is not being preserved separately in the API response before AI expansion replaces it.
⚠️ High Impact: Breaks the fundamental search UX contract — what you type is not what you see. Confusing for all users, especially non-technical.
BUG-HIGH-02 البحر (Sea) Category Contains False Positives — "الشعر بحر" Misclassified
The Sea animal sub-category shows 11 records when fewer are expected. The metaphorical Arabic phrase "الشعر بحر" (poetry is a sea) is triggering the animals classification for Sea, as the AI metadata extraction is not distinguishing between literal and metaphorical uses of "بحر".
⚠️ High Impact: Degrades content quality in the animals section. Requires refining the AI extraction prompt to distinguish literal from figurative use.
PROCESS-COOP-01 Team Cooperation — Process Observations & Recommendations
Observation (Process): Mobile and Backend teams exhibited strong collaboration and adaptability. However, Design Team repeatedly enforced a premature design freeze and forwarded artifacts to Mobile without formal architecture validation or sign-off, causing requirements drift.
Impact (Scope / Quality / Delivery): Requirements drift, blocked API integrations (hardcoded samples), missing/mismatched pages, and 52 bug reports raised to realign the product. This increased technical debt, delayed validation, and created avoidable team friction.
Root Cause (Governance): Lack of an enforced Design→Architecture Validation Gate, missing RACI sign-offs, and absent requirements traceability.
Recommendations:
  1. Introduce an enforced Design–Architecture Validation Gate (design proposal → architecture review → PO sign-off).
  2. Apply RACI to design approvals and require documented sign-offs in PRs/change logs.
  3. Time-box iterative prototyping before any design freeze (e.g., 2 iterations).
  4. Prohibit hardcoded API samples in acceptance builds; use traceable feature flags or mocks.
  5. Link design artifacts to acceptance criteria via a traceability matrix.
  6. Log integration risk in the risk register and reflect rework in sprint planning.
  7. Hold a cross-functional retrospective and update the Definition of Done (DoD).
